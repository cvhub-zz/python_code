# 🪄 Lesson 01: The Magic Wand & Variable Vault

Welcome, Apprentice Coder! Today you will learn the two most important superpowers in all of programming:
1. **`print()`**: Your Magic Wand that displays text and secret messages on the screen.
2. **Variables**: Magic storage boxes that remember names, health points, gold coins, and power levels!

---

## 🧙‍♂️ 1. The Magic Wand: `print()`

Whenever you want Python to talk to you or display something on the screen, you use the `print()` spell.

```python
print("Greetings, Wizard!")
print(42)
```

- **Speech Bubbles (Quotes `""`)**: Text inside quotes is called a **String**. Python prints it exactly as you wrote it.
- **Numbers**: Numbers don't need quotes! You can print whole numbers (called **integers**) like `10` or decimals (called **floats**) like `3.14`.
- **Comments (`#`)**: Any line starting with `#` is invisible to Python! It's a secret note for you and other coders.

---

## 📦 2. Variables: The Labeled Magic Boxes

Imagine you have a magic box. You stick a label on it that says `hero_name`, and you drop the word `"Shadow Ninja"` inside.

```python
hero_name = "Shadow Ninja"
hero_level = 5
hero_health = 100.0
is_superhero = True
```

In Python:
- The **box name** goes on the left (e.g. `hero_name`).
- The `=` sign puts the value inside the box.
- The **value** goes on the right (e.g. `"Shadow Ninja"`).

### 🔄 Updating a Variable
Variables are called *variable* because their contents can change!

```python
gold_coins = 10
print(gold_coins)  # Prints 10

# You find a treasure chest!
gold_coins = 50
print(gold_coins)  # Now prints 50!
```
