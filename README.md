## 🚀 How to Run Your Code

Every lesson is placed inside its own folder in `lessons/`. Inside each folder you will find:
1. **`README.md`**: The fun guide explaining the new powers.
2. **`examples.py`**: Try running this first to see how the code works!
3. **`challenge.py`**: Your mission! Open it and fill in the `# TODO` sections.
4. **`solutions/challenge_solution.py`**: If you ever get super stuck, check here for one way to solve it.

### Running in PyCharm:
- Right-click any `.py` file (like `examples.py` or `challenge.py`) and click **"Run 'filename'"**.

### Running from the Terminal:
```bash
# Example for Lesson 1:
python3 lessons/01_magic_wand_variables/examples.py
python3 lessons/01_magic_wand_variables/challenge.py
```

## 💡 The 3 Golden Rules of Coding

1. **Bugs are Just Clues!** 🐞 If Python gives you red text, it's not angry—it's giving you a treasure map hint to solve the mystery.
2. **Experiment & Change Things!** 🔬 What happens if you change a number? What happens if you add a word? Try it and find out!
3. **Have Fun!** 🎉 You are building real software from scratch.
